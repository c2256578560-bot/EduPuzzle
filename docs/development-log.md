## 第 0 轮：项目设计（2026-11-05）

### 1. 我提出的需求/想法
- 做一个面向大学生的学习工具，叫 EduPuzzle。
- 三个模块：用自己的资料组卷（最大亮点）、单词闯关、化学实验计算器；外加数据管理。
- 纯前端，双击 html 能跑；数据全存在浏览器本地；代码简单好讲解。
- 要求 AI 先出设计文档，再按模块一步步写代码。

### 2. AI 的实现思路与方案取舍
- **不用框架**（React/Vue），用原生 JS + Tailwind CDN：答辩时每一行都能讲清楚，不需要 npm 构建。
- **不用 ES Module**：`file://` 打开时浏览器会拦截模块加载，改用普通 `<script>` 按顺序引入。
- **存储分两层**：资料全文和试卷放 IndexedDB（容量大），设置/词库放 localStorage（简单）。
- **只存解析后的文字，不存原文件**：省空间，备份时一个 JSON 就能带走全部数据。

### 3. 本轮产出
- `docs/设计文档.md`：页面结构、存储结构、开发顺序、依赖清单、日志模板。

### 4. 已知缺陷 / 后续方向
- Tailwind、pdf.js、mammoth 走 CDN，首次打开需要联网（见 README 离线方案）。

## 第 2 轮：私有资料库 + 一键组卷（核心亮点）（2026-11-05）

### 1. 我提出的需求/想法
- 上传 PDF / TXT / Markdown / docx，打科目标签，存本地。
- 选科目、选资料，一键生成模拟卷：选择题、判断题、简答题，带参考答案。
- 试卷可预览、复制、导出 Markdown、打印；另有 5 题 / 10 题自测小练习。
- 出题必须严格限定在我上传的资料范围内。

### 2. AI 的实现思路与方案取舍
- **文件解析**：txt/md 直接读（UTF-8 出乱码时自动改用 GBK，兼容记事本文件）；docx 用 mammoth.js；PDF 用 pdf.js。
- **两种出题方式**：
  - AI 出题：调用 OpenAI 兼容接口（DeepSeek/通义/Kimi 都能用），提示词要求「只依据资料」并返回固定 JSON；返回后用 `normalizePaper()` 校验字段，防止模型输出格式不稳定导致页面报错。
  - 本地规则出题：完全离线。用浏览器自带的 `Intl.Segmenter` 中文分词统计高频术语 → 挖空出选择题、替换术语出判断题、带「是指/定义/包括」的句子出简答题。
- **资料过长**：超过 1.2 万字时均匀截取 12 段，控制 AI 调用成本和速度。
- **隐私取舍**：AI 出题必须把资料文字发给 AI 服务，这一点在界面上明确提示；介意的同学用本地规则出题即可全程离线。

### 3. 本轮产出
- `js/parser.js`（`parseFile`）
- `js/exam.js`（`Exam` 对象、`aiGenerate`、`localGenerate`、`normalizePaper`、`paperToMd`、`pickText`）
- `示例资料/无机化学复习提纲.txt`（演示用）

### 4. 已知缺陷 / 后续方向 / bug 预判
- 本地规则出题质量有限：分词偶尔把「反应物」切成「反应」+「物」，挖空会显得生硬。测试中发现章节标题被当成题目、干扰项出现「作为」「资料」等无意义词，已修复（跳过标题行、干扰项只从其它句子的考点词中挑）。
- 扫描版 PDF 没有文字层，无法提取；后续可接 OCR（如 tesseract.js）。
- 截取片段可能漏掉部分考点；后续可改为分段多次出题再合并。
- 部分 AI 服务不允许浏览器直接跨域调用（CORS），会报「Failed to fetch」，需换支持的服务或加一个小代理。

## 第 4 轮：化学实验数据计算器（2026-11-05）

### 1. 我提出的需求/想法
- 内置 EDTA 标定、动力学活化能两套模板。
- 输入初读数、终读数，自动算消耗体积、浓度、相对平均偏差、活化能。
- 结果生成规范表格，可复制到实验报告，支持导出 Markdown 表格、导入 CSV 批量计算。

### 2. AI 的实现思路与方案取舍
- **EDTA 标定**：c(EDTA) = m·(Vₐ/V₀) / (M·V)，基准物质可选 CaCO₃ / ZnO；相对平均偏差 > 0.2% 时给出提醒。
- **活化能**：对 ln k – 1/T 做最小二乘线性拟合，Ea = −斜率 × R，同时给出 A 和 R²；只有两个点时等价于两点式。
- **计算与界面分开**：`edtaCalc()`、`arrhenius()` 是纯函数，文件末尾有自检（`console.assert`），改坏公式时控制台会报警。
- 浓度保留 4 位有效数字。测试中发现表头「|dᵢ|」里的竖线会破坏 Markdown 表格，已改为「绝对偏差 dᵢ」。

### 3. 本轮产出
- `js/chem.js`（`Chem` 对象）

### 4. 已知缺陷 / 后续方向
- 有效数字按固定位数处理，未按实际读数精度自动判断。
- 可扩展更多模板：KMnO₄ 标定、HCl 标定、Q 检验剔除可疑值。

## 第 7 轮：v2 大升级——青科大全能学习工作台（2026-11-05）

### 1. 我提出的需求/想法
- 项目升级为「青科大学生全能学习工作台」，面向全校所有专业，不再局限化学。
- 四大模块：① 青科大专业课程库 + 私有资料 AI 组卷（5 种题型）；② 拍照 OCR 识别 + 可扩展计算模板市场（替代固定化学计算页）；③ 单词闯关绑定课程；④ 液态玻璃个人工作台（待办、番茄钟、学习看板、快捷入口）。
- UI 统一为液态玻璃（Glassmorphism）风格；全局设置页集中放备份、主题、模型接口。
- 开发顺序：工作台 → 课程库 → 组卷 → OCR → 单词。

### 2. AI 的实现思路与方案取舍
- **在 v1 基础上改造，不推倒重写**：存储、文件解析、出题、闯关逻辑全部复用；IndexedDB 升级到版本 2，只新增 `ocr` 表，v1 的资料和试卷都能保留。
- **液态玻璃**：背景放三团高斯模糊色块，卡片用半透明白 + `backdrop-blur` + 顶部高光阴影。全部通过 `.card` 一个类实现，改一处全站生效；三套主题只换 CSS 变量。没有加动画特效，符合「不要花哨廉价」。
- **青科大课程数据**：学院名单从青科大招生网查得（21 个学院）。招生网没有公开各学院专业表，专业和课程先按同类专业常见培养方案整理，在代码和文档里**明确标注为参考数据**，留给作者核对。数据单独放在 `courses.js`，加专业只需加一行。
- **资料按课程名归档**：不同专业的同名课程共享资料，避免重复上传。
- **题型扩充**：用 `SECTIONS` 题型表驱动预览和导出，新增题型只改一处。本地规则可出填空题，计算题只能由 AI 出（规则无法造合理的计算题）。
- **OCR 选型**：Tesseract.js 浏览器本地识别，图片不上传；识别质量不够时可点「AI 整理」，只把识别出的文字发给 AI 修正成数据表。
- **计算模板市场**：模板是统一格式的对象（列名、参数、公式、计算函数），内置 6 个（化学 2、统计 1、力学 2、电路 1），带拟合的模板自动画散点 + 拟合直线。用户可填「列名 + 公式」自定义模板，保存前先试算一次，公式写错立即提示。
- **番茄钟**：按结束时间戳计时，切到别的页面也不会走慢；用浏览器自带音频接口发提示音，不需要音频文件。

### 3. 本轮产出
- 新增：`js/courses.js`、`js/dashboard.js`、`js/course.js`、`js/templates.js`、`js/ocr.js`、`js/settings.js`
- 重写：`index.html`、`js/app.js`、`js/exam.js`
- 修改：`js/db.js`（版本 2）、`js/words.js`（绑定课程）
- 删除：`js/chem.js`（并入模板市场）、`js/data.js`（并入设置）

### 4. 实测结果与修复（AI 在浏览器中跑过）
- 工作台：添加待办、逾期标红、番茄钟一轮结束后专注分钟入账、切换到休息 ✅
- 课程库：化学与分子工程学院 → 应用化学 → 无机化学，v1 上传的资料自动归到该课程 ✅
- 本地规则组卷：5 单选 + 3 填空 + 5 判断 + 2 简答，今日刷题 +15 ✅
- 6 个内置模板示例数据全部算出结果，公式自检通过 ✅
- Tesseract 识别一张数据表图片，文字完全正确 ✅

  1. OCR 提取数据时把行首序号当成第一列、把表头「V1 V2」里的数字当数据 → 改为每行取最后 n 个数字，跳过紧跟字母的数字。
