# EduPuzzle 打包说明（PWA / Windows EXE）

> 三个产物共用同一套网页源码（`index.html` + `js/` + `lib/`）。
> 本文说明如何在自己电脑上打包 Windows EXE，以及路径、OCR、杀毒误报等常见问题。
> 不想在本机装编译环境？直接用 GitHub Actions 云端打包，见《GitHub部署说明.md》第 4 节。

---

## 1. 三个产物是怎么来的

| 产物 | 来源 | 命令 |
|---|---|---|
| ① PWA 网页应用 | 仓库根目录的网页源码，加上 `manifest.json`、`service-worker.js` | `node scripts/build-web.mjs` → `dist/`，部署到任意 HTTPS 静态网站 |
| ② Windows 单文件 EXE | Tauri 把同一份网页嵌进一个 EXE | `npx tauri build --no-bundle` |
| ③ 分享下载页 | `download.html`（内联样式，独立可用） | 随 `dist/` 一起部署 |

```
EduPuzzle/
├─ index.html  download.html  manifest.json  service-worker.js
├─ js/           业务代码
├─ lib/          第三方库（全部本地化，不访问 CDN）
│  └─ tesseract/ worker.min.js、tesseract-core-*.wasm.js、lang/（中英文语言包）
├─ icons/        PWA 图标
├─ scripts/build-web.mjs   复制网页文件到 dist/
├─ src-tauri/    Tauri 桌面壳（Rust，只有十几行）
├─ release/      放打包好的 EduPuzzle.exe（小于 100 MB 时）
└─ .github/workflows/      自动部署 / 自动打包
```

---

## 2. 环境依赖

| 依赖 | 版本 | 说明 |
|---|---|---|
| Node.js | 18+ | 运行构建脚本、Tauri 命令行 |
| Rust | stable | `rustup` 安装，**推荐 MSVC 工具链** |
| Microsoft C++ 生成工具 | 2019+ | Visual Studio Installer 勾选「使用 C++ 的桌面开发」（MSVC + Windows SDK），约 6 GB |
| WebView2 运行时 | — | Windows 10/11 一般已内置；没有就到微软官网下载「Evergreen Bootstrapper」 |

安装 Rust 后切换到 MSVC 工具链：

```bash
rustup default stable-msvc
```

> 也可以用 GNU 工具链（`stable-x86_64-pc-windows-gnu`），但必须额外安装 MinGW-w64（提供 `dlltool.exe`、`gcc`），并把它的 `bin` 目录加入 PATH，否则会报 `dlltool.exe: program not found`（见第 6 节）。

## 3. 编译步骤

```bash
npm install
```

```bash
npx tauri build --no-bundle
```

- 输出：`src-tauri/target/release/edupuzzle.exe`（单文件，网页资源已全部嵌入）
- 改名后放到仓库：`release/EduPuzzle.exe`
- 第一次编译要下载、编译 Rust 依赖，约 5~15 分钟；之后几十秒
- 需要安装包版（.exe 安装程序）时，去掉 `--no-bundle`，输出在 `src-tauri/target/release/bundle/nsis/`

开发调试（改网页后重新打开窗口）：

```bash
npx tauri dev
```

打包前会自动执行 `node scripts/build-web.mjs --tauri`，把网页文件复制到 `dist/`（不含 `release/`，避免把 EXE 再嵌进 EXE）。**新增了静态资源文件夹**时，记得加到 `scripts/build-web.mjs` 的 `ITEMS` 列表里。

## 4. 资源路径修复方案（重点：Tesseract.js wasm 与语言包）

### 问题

Tesseract.js 默认从 jsDelivr CDN 下载三样东西：Worker 脚本、wasm 识别核心、语言包。这会导致：
- PWA 离线时无法识别；
- 打包成 EXE 后，网页地址变成 `http://tauri.localhost/`，相对路径在 Worker 里解析出错，或者被墙、没网就失败；
- 部署到 GitHub Pages 子目录（`/仓库名/`）时，以 `/` 开头的路径会指到域名根目录。

### 解决

1. **全部本地化**：所有第三方文件放进 `lib/`，`index.html` 不再引用任何 CDN。
2. **用绝对地址**：Worker 内部不能可靠解析相对路径，`js/app.js` 里统一用
   ```js
   const libUrl = path => new URL('lib/' + path, location.href).href;
   ```
   根据当前页面地址生成绝对地址。本地服务器、GitHub Pages 子目录、`http://tauri.localhost` 都能正确找到文件。
3. **显式指定 Tesseract 路径**（`js/ocr.js`）：
   ```js
   Tesseract.createWorker(lang, 1, {
     workerPath: libUrl('tesseract/worker.min.js'),
     corePath:   libUrl('tesseract/'),        // 目录：自动选 simd-lstm（新设备）或 lstm（旧设备）
     langPath:   libUrl('tesseract/lang'),    // 读取 chi_sim.traineddata.gz、eng.traineddata.gz
   });
   ```
   wasm 已经内嵌在 `tesseract-core-*.wasm.js` 里，不需要服务器配置 `application/wasm` 类型。
4. **pdf.js Worker** 同样改为 `libUrl('pdfjs/pdf.worker.min.js')`。
5. **桌面版不注册 Service Worker**：资源已在 EXE 里，`IS_TAURI` 为真时跳过。

| 文件 | 大小 | 说明 |
|---|---|---|
| `lib/tesseract/tesseract-core-simd-lstm.wasm.js` | 3.9 MB | 支持 SIMD 的设备（绝大多数） |
| `lib/tesseract/tesseract-core-lstm.wasm.js` | 3.9 MB | 旧设备兜底 |
| `lib/tesseract/lang/chi_sim.traineddata.gz` | 1.7 MB | 简体中文（4.0.0_best_int） |
| `lib/tesseract/lang/eng.traineddata.gz` | 3.0 MB | 英文 / 数字 |

想加其它语言：把 `https://cdn.jsdelivr.net/npm/@tesseract.js-data/<语言>/4.0.0_best_int/<语言>.traineddata.gz` 下载到 `lib/tesseract/lang/`，再在 `index.html` 的语言下拉框里加一项。

## 5. PWA 说明

- `manifest.json`：名称、图标（含安卓自适应图标）、全屏 `standalone`、快捷入口。
- `service-worker.js`：安装时预缓存核心文件（约 3 MB）；OCR 核心和语言包第一次识别时再缓存（约 9 MB），之后完全离线可用。
- **必须 HTTPS**（或 localhost）才能注册 Service Worker、调用摄像头；GitHub Pages 自带 HTTPS。双击打开 `index.html`（file://）也能用，但没有离线缓存和摄像头。
- **发新版本**：修改 `service-worker.js` 里的 `VERSION`，用户下次打开后台更新、再下次打开生效。
- 手机拍照：「上传 / 手机拍照」按钮在手机上直接调起相机；「打开电脑摄像头」用网页摄像头接口。

## 6. 常见报错

| 报错 / 现象 | 原因 | 解决 |
|---|---|---|
| `error calling dlltool 'dlltool.exe': program not found` | Rust 用的是 GNU 工具链，缺 MinGW 的 dlltool | 推荐：装 C++ 生成工具后 `rustup default stable-msvc`；或安装 MinGW-w64 并加入 PATH；或用 GitHub Actions 云端打包 |
| `linker 'link.exe' not found` | 用 MSVC 工具链但没装 C++ 生成工具 | 安装「使用 C++ 的桌面开发」 |
| 窗口白屏 / 找不到 index.html | `dist/` 没生成 | 先运行 `node scripts/build-web.mjs --tauri`；检查 `tauri.conf.json` 的 `frontendDist` 为 `../dist` |
| 双击 EXE 没反应或提示缺 WebView2 | 系统没有 WebView2 运行时（老版本 Win10、精简版系统） | 安装 WebView2 Evergreen 运行时；或改用安装包版（去掉 `--no-bundle`，安装程序会自动下载 WebView2） |
| OCR 一直「加载识别模型…」 | 语言包 / wasm 路径不对 | 确认 `dist/lib/tesseract/lang/` 下有 `.traineddata.gz`；按 F12 看网络请求是否 404 |
| 改了代码但页面没变化 | 浏览器 / Service Worker 缓存 | 网页 `Ctrl + F5`；PWA 改 `VERSION`；EXE 重新编译 |
| 「Windows 已保护你的电脑」（SmartScreen） | EXE 没有代码签名证书、下载量少 | 点「更多信息 → 仍要运行」；正式发布可购买代码签名证书 |
| 杀毒软件报毒 / 自动删除 | 未签名的新程序被启发式误报，常见于 360、火绒等 | 把 EXE 加入信任区；向杀毒厂商提交误报申诉；演示时可直接用在线 PWA 版 |
| 项目放在中文路径下编译出错 | 部分工具链对非 ASCII 路径支持不好 | 把项目放到纯英文路径（如 `D:\EduPuzzle`）再编译 |
| `npm ci` 报错 | 缺少 `package-lock.json` | 先在本机运行一次 `npm install` 并提交 `package-lock.json` |
