# EduPuzzle 青科大学生全能学习工作台

面向青岛科技大学全体本科生的液态玻璃风格学习平台。按【学院 → 专业 → 年级学期 → 课程】组织学习；**有资料就用资料出题，没资料直接用内置题库出题**；拍照识别实验数据，套用 32 个实验模板自动计算（含《无机及分析化学实验》全套 17 个）；单词闯关；番茄专注工作台。所有数据只存在你的设备上。

> 创意：项目作者（参赛学生）｜代码实现：AI 辅助（Claude）

## 三种使用方式（同一套源码）

| 产物 | 适合 | 怎么用 |
|---|---|---|
| 📱 **PWA 网页应用** | 手机（安卓 / iPhone）、任何电脑浏览器 | 打开 Pages 链接 → 「添加到主屏幕」；打开过一次后可离线使用 |
| 💻 **Windows 单文件 EXE** | Windows 10 / 11 | 下载 `EduPuzzle.exe` 双击运行，无需安装 |
| 🔗 **分享下载页** | 对外分享 | `download.html`：项目介绍、截图、EXE 下载、在线体验入口 |

本地预览（在项目文件夹里）：

```bash
python -m http.server 8000
```

然后打开 http://localhost:8000 （PWA）和 http://localhost:8000/download.html （分享页）。也可以直接双击 `index.html`，但没有离线缓存和摄像头。

- 打包 EXE：见 [打包说明.md](打包说明.md)
- 部署到 GitHub Pages、发布 EXE：见 [GitHub部署说明.md](GitHub部署说明.md)

## 快速体验（3 分钟）

1. **工作台**：加一条待办，开始番茄钟。
2. **课程库**：选「化学与分子工程学院 → 化学 → 大一上 → 无机及分析化学」。
   - 「📚 内置题库组卷」→「离线题库抽题」→「生成模拟卷」：不用上传任何资料。
   - 「📄 私有资料组卷」：上传 `示例资料/无机化学复习提纲.txt` 再出题。
3. **实验计算**：课程「无机及分析化学实验」→「本课程配套实验模板」→「3. 混合碱的测定」；或拍照识别原始记录后「提取数字到数据表」。
4. **单词闯关**：自带 20 个化学专业词汇。
5. **设置**：填 DeepSeek 等服务的 API Key，两种组卷模式都能用 AI 出题。

## 功能

| 模块 | 功能 |
|---|---|
| 个人工作台 | 待办 / 通知 / 实验安排 / 考试；番茄钟；今日专注、刷题、闯关、待办看板；近 7 天专注图；错题提醒 |
| 课程库 & 组卷 | 21 个学院、80 个专业、6 个学期；私有资料组卷与内置题库组卷；5 种题型；随堂自测；答案解析；导出 / 打印 |
| 拍照识别计算 | 上传 / 手机拍照 / 电脑摄像头；Tesseract 本地识别（离线）；32 个实验模板，按课程筛选、搜索；相对平均偏差；拟合图；讨论提示；自定义模板 |
| 单词闯关 | 词库绑定专业·学期·课程；导入 txt/csv；关卡；错题本 |
| 设置 | AI 接口；三套主题；备份 / 恢复 / 清空 |

## 怎么扩充

- **专业 / 学期课程**：`js/courses.js`，给专业加 `terms: { '大一上': [...], ... }`
- **内置考点 / 离线题库**：`js/outlines.js` 的 `OUTLINES`、`QBANK`
- **实验模板**：页面上「自定义计算模板」，或在 `js/templates.js` 照同类模板复制（`titration` / `perRow` / `stdCurve`）
- **新增静态文件夹**：加到 `scripts/build-web.mjs` 的 `ITEMS`，以及 `service-worker.js` 的 `CORE`（需要离线时）

> 数据说明：学院名单来自青科大招生网；专业名单已对照各学院官网核对。学期课表中化学类按作者示例整理，其余为参考数据；实验模板参数默认值是常见值。请以本校培养方案和实验讲义为准。

## 隐私说明

- 资料、试卷、识别记录、词库、待办、设置全部存在本机（浏览器 IndexedDB / localStorage），OCR 在本地完成。
- 使用 AI 时：私有资料模式发送所选资料文字；内置题库模式只发送专业、学期、课程名和考点范围。
- 备份文件里含 API Key，分享前请删除。

## 常见问题

- **改了代码但页面没变化**：`Ctrl + F5` 强制刷新；PWA 需修改 `service-worker.js` 的 `VERSION`。
- **内置题库提示「暂无离线题库」**：目前离线题库只有《无机及分析化学》，其它课程请配置 AI。
- **识别不准**：拍正、拍清楚；手写体识别后请校对，或用「AI 整理」。
- **EXE 被拦截**：见《打包说明.md》第 6 节（SmartScreen、杀毒误报）。
