# EduPuzzle 青科大学生全能学习工作台 · 项目设计文档（v3）

> 创意与需求：项目作者（参赛学生）提出；技术方案与代码实现：AI（Claude）辅助完成。
> v3 主要变化：课程库增加「年级学期」层级；新增「内置题库组卷」（无资料也能出题）；实验模板从 6 个扩充到 32 个，其中《无机及分析化学实验》17 个；模板库支持按课程筛选、关键词搜索，每个模板带结果讨论提示；词库绑定学期课程。

## 1. 页面结构

| 页面 | hash | 内容 |
|---|---|---|
| 个人工作台（首页） | `#home` | 问候 + 当前学期课程、快捷入口；今日专注 / 今日刷题 / 闯关进度 / 待办看板；待办 & 通知；番茄钟；近 7 天专注图；错题提醒 |
| 课程库 & 组卷 | `#course` | 学院 → 专业 → **年级学期** → 课程；课程空间内切换 **【私有资料组卷】/【内置题库组卷】**；组卷参数（5 种题型）；试卷预览导出；历史试卷；**本课程配套实验模板**；本课程词库 |
| 拍照识别计算 | `#ocr` | 拍照 / 上传；Tesseract 本地识别；校对；提取数字或 AI 整理；**实验模板库（按课程筛选 + 搜索）**；结果表格、拟合图、讨论提示；自定义模板 |
| 单词闯关 | `#words` | 词库（绑定专业·学期·课程）、导入、手动加词、关卡、错题本 |
| 设置 | `#settings` | AI 接口、主题、本地资料、备份 / 恢复 / 清空 |

## 2. 本地数据结构

**IndexedDB**（数据库 `edupuzzle`，版本 2）：`docs` 资料、`papers` 试卷、`ocr` 识别历史（字段同 v2）。

**localStorage**（前缀 `ep_`）

| 键 | 内容 |
|---|---|
| `ep_myCourse` | 当前课程 `{ college, major, term, course }` |
| `ep_customCourses` | 自定义课程 `{ '专业名|学期': [课程...] }` |
| `ep_wordbanks` | 词库 `[{ id, name, course, major, term, unlocked, words }]` |
| `ep_customTpl` | 自定义实验模板 `[{ id, course, cat, name, cols, formula, result }]` |
| `ep_todos` / `ep_stats` / `ep_wordlog` / `ep_aiConfig` / `ep_theme` | 同 v2 |

> 资料和试卷按「课程名」归档。同一门课不同学期内容不同的，用不同课程名区分（如「高等数学C（上）」「高等数学C（下）」）。

## 3. 青科大【学院 → 专业 → 年级学期 → 课程】数据结构（`js/courses.js`）

```js
const TERMS = ['大一上', '大一下', '大二上', '大二下', '大三上', '大三下'];
const COMMON_TERMS = { '大一上': ['高等数学（上）', ...], ... };       // 理工科公共课学期表
const ARTS_COMMON_TERMS = { ... };                                    // 文科/艺术类（学院带 arts: true）
const CHEM_TERMS = { '大一上': ['高等数学C（上）', '无机及分析化学', '无机及分析化学实验', ...], ... };
const QUST = [
  { college: '化学与分子工程学院', campus: '四方校区', verified: true, src: '出处', majors: [
    { name: '化学', terms: CHEM_TERMS },                       // 写了完整学期课表
    { name: '某专业', courses: ['核心课1', '核心课2', ...] },   // 没写学期：自动分配（见下）
  ]},
];
```

- **专业名单**：已对照 20 个学院官网核对（80 个专业），`verified` / `src` 标明核对状态与出处。
- **学期课表**：化学类（化学、应用化学、能源化学）按作者给出的「大一上 / 大一下」示例整理；化工类（化工、制药、药物制剂）为参考课表；其余专业 = 公共课学期表 + 核心课按顺序分配到大一下 ~ 大三下（**参考数据**，需按培养方案修正：给专业加 `terms` 即可覆盖）。

## 4. 双模式组卷

| | 模式 A：私有资料组卷 | 模式 B：内置题库组卷 |
|---|---|---|
| 需要上传资料 | 是 | **否** |
| AI 出题的上下文 | 所选资料文字（超 1.2 万字均匀截取） | 学院 + 专业 + 学期 + 课程名 + 内置考点范围 |
| 离线方式 | 本地规则出题（分词挖空） | 从离线题库随机抽题（选项顺序也打乱） |
| 数据文件 | IndexedDB `docs` | `js/outlines.js` 的 `OUTLINES`（18 门课考点）、`QBANK`（无机及分析化学 25 题） |

没有内置考点的课程，AI 按该课程通用本科教学大纲出题；没有离线题库的课程需配置 AI。

### 其他理工科（15 个）

- **大学物理实验**：单摆测 g、杨氏模量（光杠杆）、惠斯通电桥、光电效应测普朗克常量、胡克定律、自由落体、伏安法测电阻
- **化工原理实验**：雷诺实验（流型判断）、套管换热器总传热系数
- **环境监测**：COD（重铬酸钾法）、浊度（标准曲线）
- **物理化学实验**：凝固点降低测摩尔质量、黏度法测分子量、反应活化能
- **通用数据处理**：重复测量统计（含 Q 检验、95% 置信区间）

每个模板包含：数据记录表（列名）、参数、计算公式、平均值 / 相对平均偏差 / 标准偏差、超限警告、结果讨论提示、Markdown 导出；拟合类模板自动画散点 + 拟合直线。

### 模板工厂（新增模板只需写数据）

- `titration({...})`：滴定类，自动显示消耗体积、偏差限 0.2%
- `perRow({...})`：每行算结果再汇总
- `stdCurve({...})`：标准曲线法
- 其它拟合类直接写 `calc(rows, p)`
